About Event

Impetus.AI is an inter-college coding and machine-learning challenge organized by the students of III AIML. The event bridges the gap between theory and practice by encouraging participants to build real-world ML projects from scratch using VS Code and open-source libraries, with a special focus on Edge AI. Participants will develop their models, demonstrate their functionality, and present their ideas to a panel of judges. Outstanding projects will get an opportunity to be showcased at the upcoming Tech Expo.

Event Rules

  • 1

    Use only approved AI tools such as ChatGPT, Claude, or Gemini for guidance, code generation, debugging, and documentation.

  • 2

    Participants must build the project themselves. AI tools are assistants only; they should not submit fully generated projects without understanding them.

  • 3

    Follow the complete ML pipeline while developing the project. Skipping major stages is not allowed.

  • 4

    Use Visual Studio Code (VS Code) only as the development environment.

  • 5

    No VS Code extensions (such as AI coding assistants or auto-completion extensions) are allowed during the event.

  • 6

    Do not use external AI applications like Antigravity, Cursor, Windsurf, GitHub Copilot, Replit AI, or similar coding assistants.

  • 7

    Internet usage is limited to accessing the approved AI tools and official documentation only. Copying projects from GitHub or other websites is prohibited.

  • 8

    Participants must be able to explain their code, model, dataset, and every step of the ML pipeline during evaluation.

  • 9

    Use only legal and publicly available datasets or datasets provided by the organizers. Mention the dataset source in your submission.

  • 10

    Submit the complete project including source code, trained model (if applicable), README, and a brief explanation of the ML pipeline followed.
