About Event

Impetus.AI is a premium inter-college coding and model-building challenge presented by the students of III AIML. Designed specifically to bridge the gap between academic theory and industry practice
Core Philosophy
The Problem:
        Most students learn Artificial Intelligence and Machine Learning theory purely from textbooks, yet they frequently struggle to write functional, real-world project code
The Solution:
       Impetus.AI provides an immersive, experiential ecosystem where students don't just learn—they build. Through structured mentorship and hands-on coding, the event empowers beginners to build a portfolio-ready machine learning project from scratch.

Key Event Highlights & Focus Areas Emphasis on Edge-AI:
         The competition focuses on transitioning students into practical engineers by proving that AI can run locally and efficiently in the physical world. Strict Development Environment: To mirror true industry-level engineering, all teams must build their models exclusively inside VS Code using open-source libraries (like NumPy, Pandas, and Scikit-Learn) with zero integrated AI code assistants allowed. The Pitch Matters: A working model is only half the battle. Impetus.AI heavily emphasizes presentation skills; individuals must clearly articulate their model's backend logic to a panel of expert judges to secure their designated marks. Future Exposure: The highest-performing models will not only receive official mementos of appreciation but will also earn an exclusive featured spot to showcase their project at the upcoming Tech Expo event.

Vision & Impact
         Ultimately, Impetus.AI serves as a vital launchpad for experiential tech education. By keeping the registration fee low, the primary goal remains highly student-centric: to foster academic growth, encourage healthy multi-stream collaboration, and firmly position our institution as a regional hub for practical technical excellence.

Event Rules

  • 1

    Use only approved AI tools such as ChatGPT, Claude, or Gemini for guidance, code generation, debugging, and documentation.

  • 2

    Participants must build the project themselves. AI tools are assistants only; they should not submit fully generated projects without understanding them.

  • 3

    Follow the complete ML pipeline while developing the project. Skipping major stages is not allowed.

  • 4

    Use Visual Studio Code (VS Code) only as the development environment.

  • 5

    No VS Code extensions (such as AI coding assistants or auto-completion extensions) are allowed during the event.

  • 6

    Do not use external AI applications like Antigravity, Cursor, Windsurf, GitHub Copilot, Replit AI, or similar coding assistants.

  • 7

    Internet usage is limited to accessing the approved AI tools and official documentation only. Copying projects from GitHub or other websites is prohibited.

  • 8

    Participants must be able to explain their code, model, dataset, and every step of the ML pipeline during evaluation.

  • 9

    Use only legal and publicly available datasets or datasets provided by the organizers. Mention the dataset source in your submission.

  • 10

    Submit the complete project including source code, trained model (if applicable), README, and a brief explanation of the ML pipeline followed.
